# Sistem-Deteksi-dan-Estimasi-Jarak-Objek-Stereo-Vision
Penelitian Sistem Deteksi dan Estimasi Jarak menggunakan YOLO+Hungarian Matching untuk mendeteksi dan Penerapan Teorema Pythagoras untuk mengestimasi jarak robot ke brondolan sawit. Penelitian ini menggunakan Kamera ZED 2 untuk pengambilan dataset training maupun uji.
